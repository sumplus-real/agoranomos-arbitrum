Build scope and trust boundaries

The evidence model, verifier rules and agent/settlement separation extend the earlier Sumplus Agoranomos project. The Arbitrum adaptation adds this chain-specific integration and public synthetic demonstration. The submission repository documents the build history.

This prototype uses deterministic verification rules. It does not claim a live AI model call or a TEE deployment. The verifier and evidence ingestion are trusted components. A signature proves the verifier authorized the bound fields; it does not prove the source evidence is truthful.
